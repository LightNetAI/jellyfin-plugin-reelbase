Create a key under Account → API keys on your Reelbase instance and paste it here. Keys are read-only by default, which is all the plugin needs. Without a key no metadata is looked up at all.
The address of the Reelbase instance to read from. Leave this at https://api.reelbase.me unless you run your own.

There is nothing to set for the request allowance. The plugin reads it from the API's own X-RateLimit headers once at the start of each run, counts its own requests from there and stops at 95% of the figure, which leaves the rest of the account room to work. A nightly task named Refresh music video metadata from Reelbase works through the library and carries on where it stopped on the following run, which is what lets a library larger than one day's allowance finish over several days. If the API refuses a request and says how long to wait, the plugin waits that long, or stops until then when the wait is long.

How long a response is reused before it is fetched again. The daily allowance is small enough that caching cannot be turned off; the default is 24 hours.
